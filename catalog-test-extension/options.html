Réglages

1. Consentement

Sans ce consentement, rien n’est envoyé. Tu peux le retirer à tout moment.

2. Clé API

La clé est stockée en clair dans chrome.storage.local : elle reste sur cet ordinateur (non synchronisée), mais toute personne ayant accès à ton profil Chrome pourrait la lire. Utilise une clé dédiée avec une limite de dépense.

3. Ce qui est partagé avec le LLM

Rien n’est coché par défaut. Les cases sont actives seulement si tu as donné ton consentement.

4. Mes données

L’export ne contient pas ta clé API. La suppression efface tes réglages (clé API comprise) et les données collectées ; le catalogue public de recommandations est conservé.
